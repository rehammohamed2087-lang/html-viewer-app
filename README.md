# مكتبة الدروس (عارض HTML)

تطبيق Django: الأدمن ينظّم الملفات في **مراحل ومواد**، والزوار يتصفحون الأقسام من الصفحة الرئيسية.

## كيف يعمل
- **الصفحة الرئيسية**: المراحل، وتحت كل مرحلة موادها، ثم ملفات كل مادة.
- **التصنيف**: المرحلة ← الصف ← المادة (مثال: الإعدادية ← الصف الأول ← العلوم).
- **الرفع (للأدمن)**: من «لوحة التحكم» تختار **المرحلة ← الصف ← المادة** أولاً، وبعدها فقط يُفتح اختيار ملف/ملفات HTML.
- **ملف مجاني واحد**: يحدده الأدمن (عند الرفع أو زر «اجعله مجاني»)، ويفتحه أي زائر بدون كود.
- **باقي الملفات**: تحتاج **كود دخول** ينشئه الأدمن من «أكواد الدخول» ويرسله للطالب على واتساب. يمكن إيقاف الكود أو حذفه أو تحديد مدة له.
- **رقم واتساب الأدمن**: يُضبط من «الإعدادات» ويظهر أسفل كل صفحات الموقع.
- الملفات المدفوعة محمية في الخادم أيضاً (رابط `/raw/` يرفض من ليس لديه كود).

## تشغيل محلي
```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```
ثم ادخل `/login/` وافتح لوحة التحكم، وابدأ بـ «المراحل والمواد».

## النشر على Render
كما في السابق (`render.yaml` + `DATABASE_URL` + `ADMIN_USERNAME` + `ADMIN_PASSWORD`). سكربت البناء يشغّل `migrate` تلقائياً.
